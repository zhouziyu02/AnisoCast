AnisoCast implementation details

Architecture. The supported model is CIRT/models/soon.py, selected with model_name='soon'. A longitude-wide Conv2d embeds a daily [B,63,121,240] field into [B,121,C] latitude-ring tokens. Each block applies the same latent feature-axis spectral operator before and after a latitude-axis gated depthwise convolution, plus a residual MLP. This palindromic composition is inspired by symmetric operator splitting. The implementation does not establish a formal O(dt^3) error guarantee for learned blocks or an exact physical time-step integrator. FFT operates on latent features. num_heads and patch_size are compatibility arguments unused by the backbone.

Data. There are 60 pressure-level channels (six variables at ten levels) and three surface channels. Pressure variable/level order is defined in data/config.py and CIRT/config.py. Daily ERA5 fields are sampled by index stride 6 from 0.25 to 1.5 degrees (121x240), without conservative regridding. Downloaders fill missing values with zero. Normalization uses unweighted training-period time/grid mean and population standard deviation, with float64 accumulation. Default statistics dates are 1979-01-01 through 2016-12-31; 2017/2018 are excluded. Missing data coverage and malformed inputs fail explicitly.

Forecast definition. One daily state initializes the forecast. lead_time=15 and n_step=28 define two 14-day target means: days +15..+28 and +29..+42, inclusive. n_step is the future target span, not historical input context. Outputs are [B,2,63,121,240]. Train/validation/test years are 1979-2016/2017/2018; targets stay inside each split.

Training defaults. The launcher uses batch32 perGPU, embed256, depth8, decoder_depth2, lr1e-3, AdamW weight_decay1e-5 and eps1e-8, epochs20, and cosine T_max500 with eta_min=lr/10. The README example explicitly selects depth7/decoder1. The current loss is unweighted MSE in normalized space. The schedule does not reach eta_min within a default 20-epoch run. Gradient norm clipping1 is handled by Lightning after gradient unscaling. GPU precision defaults16-mixed; CPU32-true. Seed42 is recorded but cross-device bitwise reproducibility is not asserted. Hyperparameter-search results are not included in this repository.

Evaluation. Checkpoint architecture is authoritative and incompatible state dictionaries fail strict loading. Explicit configuration can relocate data or select test years and batch/worker counts. The test tail batch is retained. Predictions and targets are denormalized before computing per-channel/window scores. RMSE/Bias use cosine-latitude adjustment. ACC uses one cosine weight and the scalar training-channel mean as the anomaly baseline, not a seasonal/spatial climatology. The inherited MS-SSIM rescales each field independently; spectral metrics use radial spectra of sample-mean fields with percentile0.9. These specific metric definitions should be checked when comparing implementations.

Verification scope. Syntax and entry-point checks plus small synthetic regression tests are provided. Full 1979-2018 ERA5 retrieval, complete normalization over that dataset, full-scale GPU training, and published forecast scores have not been rerun. This repository does not include pretrained paper checkpoints or original experiment logs. Runtime/data corrections in this revision can change results relative to earlier revisions; historical result agreement is not asserted.
