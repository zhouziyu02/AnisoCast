Implementation Details

Model Architecture. SOON (Symmetric Orthogonal Operator Network) is built upon the symmetric operator splitting framework, implementing Strang splitting with O(dt³) local error accuracy. The model consists of three main components: (1) Patch embedding layer that compresses the longitude dimension (240) into channel features, transforming input from [B, V, H, W] to [B, H, C] where H=121 (latitude) and C is the embedding dimension; (2) Symmetric operator blocks that alternate between spectral and spatial operators along feature and sequence axes respectively; (3) Decoder head with configurable depth for output prediction. The spectral operator uses FFT-based learnable complex weights initialized near-identity, while the spatial operator employs depthwise 1D convolutions with Gated Linear Units (GLU) and kernel size 7. All normalization layers use RMSNorm to preserve phase information, with layer scale initialization set to 1e-3.

Data Configuration. We use ERA5 reanalysis data at 1.5° spatial resolution (121×240 grid points covering global latitude and longitude). The dataset includes 63 variables: 60 pressure-level variables (6 parameters × 10 pressure levels: 10, 50, 100, 200, 300, 500, 700, 850, 925, 1000 hPa) and 3 single-level variables (10m u-component of wind, 10m v-component of wind, 2m temperature). The pressure-level parameters are geopotential, specific humidity, temperature, u-component of wind, v-component of wind, and vertical velocity. Data is split temporally: training years 1979-2016 (38 years), validation year 2017, and test year 2018. The model predicts 2 time steps ahead (14 days total) with a lead time of 15 days. Input sequences use 28 time steps (n_step=28) for context. All variables are normalized using climatological mean and standard deviation computed from the training period.

Training Configuration. Models are trained using PyTorch Lightning with distributed data parallel (DDP) on 8 GPUs by default. The batch size is set to 32 per GPU, resulting in an effective batch size of 256. We use AdamW optimizer with learning rate 1e-3, weight decay 1e-5, and epsilon 1e-8. The learning rate follows a cosine annealing schedule with T_max=500 and minimum learning rate set to 1/10 of the initial learning rate. Gradient clipping is applied with maximum norm 1.0 to stabilize training. Training runs for 20 epochs with 16 data loading workers per GPU. The loss function is mean squared error (MSE) computed over all variables and time steps.

Hyperparameter Search. We conducted extensive hyperparameter search over the following ranges: embedding dimension {128, 192, 256, 384, 512}, model depth {4, 5, 6, 7, 8, 10}, decoder depth {1, 2, 3}, learning rate {5e-4, 1e-3, 2e-3, 5e-3}, MLP ratio {2.0, 4.0, 6.0}, drop path rate {0.0, 0.1, 0.2}, and dropout rate {0.0, 0.1, 0.2}. The number of attention heads is fixed at 16 (though unused in SOON's operator blocks, kept for API compatibility). The best configuration found is: embedding dimension 256, depth 7, decoder depth 1, learning rate 1e-3, MLP ratio 4.0, drop path 0.1, and dropout 0.1. This configuration achieves the best validation performance on the 2017 validation set.

Evaluation Metrics. Model performance is evaluated using multiple metrics: Root Mean Squared Error (RMSE), Bias, Anomaly Correlation Coefficient (ACC), Multi-Scale Structural Similarity Index (MS-SSIM), Spectral Divergence (SpecDiv), and Spectral Resolution (SpecRes). Metrics are computed for each variable at each forecast lead time (step 0 and step 1, corresponding to 7 and 14 days ahead). ACC is computed separately for pressure-level and single-level variables using their respective climatological baselines. All metrics are calculated after denormalizing predictions and ground truth using the climatological statistics.

Technical Details. The model is implemented in PyTorch 2.3.1 with PyTorch Lightning 2.0.9. Training uses mixed precision (FP16) on GPU for efficiency. The spectral operator's FFT operations are forced to FP32 to avoid numerical issues with complex half precision. Positional embeddings are learnable parameters initialized with truncated normal distribution (std=0.02). The patch embedding uses a 2D convolution with kernel size [1, 240] to compress longitude into channels. All linear layers use truncated normal initialization (std=0.02) for weights and zero initialization for biases. The model outputs predictions in the format [B, 2, V, H, W] where the second dimension represents the two forecast time steps.
